## Goal

The web build installs to the iPhone home screen with an icon and name, and opens with no signal because the shell is precached. `SPEC.md` §2 PWA, §5.

## Scope

`apps/tracker/public/manifest.json`, `public/sw.js`, `public/icons/`, a post-export script `scripts/inject-pwa.mjs`, `index.html` template additions.

## Acceptance criteria

- [ ] Manifest with name, short name, `display: standalone`, theme and background colors for light and dark, 192 and 512 px icons plus an Apple touch icon.
- [ ] Service worker precaches the exported shell (HTML, JS, CSS, fonts) with a build hash, network-first for everything under the Supabase URL, and never caches auth responses.
- [ ] Post-export step injects the manifest link, Apple meta tags, and worker registration into `dist/index.html`; `pnpm -F tracker export:web` runs it.
- [ ] Old caches are purged on activate; a new build shows a "refresh to update" toast rather than silently mixing versions.
- [ ] Playwright (`iphone` project): manifest is served, worker registers, and after going offline a reload of `/` still renders the tab shell.

## Verification

```bash
pnpm -F tracker export:web && pnpm -F tracker e2e -- --grep pwa
```

## Out of scope

Web Push (M2). Native builds.
