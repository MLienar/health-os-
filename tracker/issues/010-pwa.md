## Goal

The web build installs to the iPhone home screen with an icon and name, and opens with no signal because the shell is precached. `SPEC.md` §2 PWA, §5.

## Scope

`apps/tracker/public/manifest.json`, `public/sw.js`, `public/icons/`, a post-export script `scripts/inject-pwa.mjs`, `index.html` template additions.

## Acceptance criteria

- [x] `public/manifest.json`: name, short name, `display: standalone`, `id`/`start_url`/`scope`, background and theme colors, 192/512 icons (`any` + `maskable`). Light/dark theme colors are `<meta name="theme-color" media=…>` tags in `index.html` (a manifest holds one). Apple touch icon 180 px. Icons are generated deterministically by `scripts/gen-icons.mjs` (zero deps, PNG encoder included); `assets/icon.png` 1024 px restored in `app.json` for future native builds.
- [x] `public/sw.js`: precaches the exported shell (46 files: HTML, JS, CSS, fonts, icons, manifest) under a cache named by a build hash; same-origin assets cache-first, navigations network-first with `index.html` fallback; **any cross-origin request (Supabase API, Auth, food APIs) is passed through untouched and never cached**.
- [x] `scripts/inject-pwa.mjs` runs after export (`export:web` script): fills the precache list and hash into `dist/sw.js`, injects manifest link, two theme-color metas, Apple metas, icons, and the registration script into `dist/index.html`; refuses to run twice.
- [x] Old `health-os-*` caches are deleted on activate. A waiting worker shows a "refresh to update" toast (`pwa.updateToast`); tapping it posts `SKIP_WAITING` and the page reloads on `controllerchange`. **Bug found and fixed during verification:** the first install's `controllerchange` (from `clients.claim()`) also triggered the reload, which flashed the page and broke tests; reload now only happens after the user taps the toast. The toast path itself is not covered by an automated test (needs two different builds); verified by reading the code only.
- [x] Playwright `e2e/pwa.spec.ts`: manifest served and standalone, all icon URLs 200, install metadata present, worker active + cache populated, then `context.setOffline(true)` and a navigation to `/diary` renders the shell. **Deviation:** runs in a new `pwa` project (Chromium at 390×844 mobile emulation) rather than the WebKit `iphone` project, because Playwright cannot observe service workers in WebKit. 9/9 across all three projects, twice in a row.
