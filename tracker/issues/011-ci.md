## Goal

Every push to `main` and every branch runs the full verification ladder on free Linux minutes, so the agent's local checks are confirmed independently. `SPEC.md` §10 repo tooling.

## Scope

`.github/workflows/ci.yml`, `.github/workflows/keepalive.yml` (skeleton, enabled in #013).

## Acceptance criteria

- [ ] `ci.yml` jobs: `static` (pnpm install with cache, `biome check`, `tsc`, `tracker check`), `unit` (Jest all packages), `db` (Supabase CLI starts Postgres in the runner, `db reset`, `test db`), `e2e` (export web, serve `dist/`, Playwright smoke in the `iphone` project, upload screenshots and traces as artifacts).
- [ ] Jobs run in parallel; total wall time under 8 minutes.
- [ ] `pnpm` version pinned via `packageManager`; Node version from `.nvmrc`.
- [ ] Workflow uses no secrets; local Supabase only. Fails clearly if Docker is unavailable on the runner.
- [ ] A status badge in the repo `README.md` (create the README with a two-paragraph overview and links to `SPEC.md`, `CLAUDE.md`, `tracker/BOARD.md`).
- [ ] `keepalive.yml` exists, scheduled twice weekly, but the ping step is skipped while the `SUPABASE_KEEPALIVE_URL` secret is unset.

## Verification

Push the branch and link the green run in the log. Locally: `act` is not required.
